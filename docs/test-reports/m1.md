**Bug found on the phone and fixed:** the Codex endpoint streams without a `Content-Type` header, and the
first version rejected that as "not a stream" (`ProviderChanged`). Now only a declared non-stream type is
rejected; regression test added. Found through the new codes-only `ProviderResponse` log event.
